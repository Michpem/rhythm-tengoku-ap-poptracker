# Rhythm Tengoku Poptracker

This a very simple tracker for [Rhythm Tengoku](https://thelx5.github.io/tengoku/index.html) made for the purposes of checking what you have unlocked. Perfect for async sessions.

## Installation

1. Make sure you have the latest PopTracker installed.  Get the latest release [here](https://github.com/black-sliver/PopTracker/releases).
2. Download the latest release of this pack from the releases section.
3. Place it into the `packs` folder in your PopTracker installation folder and you're all set!
